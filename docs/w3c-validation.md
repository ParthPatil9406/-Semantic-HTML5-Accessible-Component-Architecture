# W3C Validation Evidence

## Official validator

https://validator.w3.org/nu/

## Required validation run

Upload or point the validator to each HTML document and confirm:

- No HTML syntax errors.
- No unclosed or incorrectly nested elements.
- Valid attributes.
- Valid document structure.

### Files

- `index.html`
- `users.html`
- `reports.html`
- `accessibility.html`
- `contact.html`

> The validator result should be captured as a screenshot or linked result in the final GitHub submission. Do not claim a W3C result until the files have actually been submitted to the validator.
