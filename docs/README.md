# Documentation

## Expected Proof

1. GitHub repository URL.
2. Clean semantic HTML5 pages.
3. Keyboard-operable navigation and dialogs.
4. Accessible forms with labels, fieldsets and validation.
5. Accessible tables with captions and scoped headers.
6. W3C Nu HTML Checker result showing zero errors.

## Validation

Validate these files using the official W3C Nu HTML Checker:

- `index.html`
- `users.html`
- `reports.html`
- `accessibility.html`
- `contact.html`

Official validator: https://validator.w3.org/nu/

The repository intentionally avoids framework-generated markup so the semantic structure is directly reviewable.
